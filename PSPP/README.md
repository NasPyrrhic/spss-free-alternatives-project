## 3. Guía de Uso de GNU PSPP (`/pspp/README.md`)

Esta carpeta contiene el archivo de sintaxis `.sps` compatible con GNU PSPP e IBM SPSS Statistics.

### Instalación de GNU PSPP

- **Windows:** Descarga los instaladores ejecutables desde [gnu.org/software/pspp/get.html](https://www.gnu.org/software/pspp/get.html).
- **Linux (Ubuntu/Debian):**

```bash
sudo apt install pssp
```

- **macOS:** Instalación vía Homebrew con:

```bash
brew install pssp
```
