## 2. Guía de Uso de R (`/r/README.md`)

Esta carpeta contiene el script básico de prueba escrito en el lenguaje estadístico **R**.

### Instalación de R y RStudio

1. Instala el motor de R desde la red CRAN oficial: [cloud.r-project.org](https://cloud.r-project.org/)
2. Instala el entorno de desarrollo RStudio (Posit Desktop): [posit.co/download/rstudio-desktop](https://posit.co/download/rstudio-desktop/)

### Ejecución del Código "Hola Mundo"

- **Desde RStudio:** Abre el archivo `hola_mundo.R`, selecciona todo el código (`Ctrl + A` o `Cmd + A`) y presiona el botón **Run** o la combinación `Ctrl + Enter`.
- **Desde la Terminal:**

```bash
Rscript hola_mundo.R
```
